# 美股早晚盘

**网站：<https://stocks.bjxihi.com>**

每天两条美股中文资讯，浓缩加一点解读：盘前新闻与盘后个股复盘。

## 栏目

- **早盘新闻**：每天美东开盘前，股指期货、盘前异动、重要数据与财报
- **晚盘个股**：每天美股收盘后复盘，领涨/领跌板块与有重大新闻的公司
- **每周复盘**：每周六，本周回顾与下周前瞻
- **每周一股**：每周日，精选一支本周值得跟踪的股票
- **每周前瞻**：每周日，下周美股重要数据、重要财报与关键事件
- **美股百科**：不定期，美股基础知识（交易时间、指数、财报、ETF、术语），长效内容，永久保留
- **术语词典**：不定期，美股财报与研报常用术语，长效内容，永久保留
- **ETF 指南**：不定期，宽基、行业与红利 ETF 怎么选，长效内容，永久保留
- **公司档案**：不定期，已覆盖公司的业务与关键数字（只讲事实，不做推荐），长效内容，永久保留

## 说明

- 内容每天自动更新，发布时间为美东时间
- 内容仅供参考，不构成投资建议；数据来自公开市场信息，正式决策请以券商行情为准
